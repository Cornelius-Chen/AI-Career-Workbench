# 复制给自己的 Agent

请帮我在这台 Mac 安装并实际用起来这个 AI 求职工作台：https://github.com/Cornelius-Chen/AI-Career-Workbench 。默认单人使用；不要先要求 GitHub 登录、协作密钥或 Cloudflare 账号。

先阅读源码中的 AGENTS.md、docs/GETTING-STARTED.md 和 docs/LOCAL-WORKBENCH.md。检查 Node.js 22.13+ 与 Git，克隆到一个新目录，安装依赖，运行 `npm run local:setup -- --name "我的显示名称"` 和 `npm run local:start`，在 Chrome 打开本机工作台。已有 .local/ 时保留数据库、文件和密钥，不能导入作者或旧云端的私人数据覆盖它。

安装后实际确认页面、成员身份、空白资料、文件上传入口与使用引导可用。让我提供真实简历并填写全职或暑期实习、目标地区和年份；根据真实材料整理资料，不猜联系方式、学校、经验、成绩或工作授权。完整申请资料和经历事实由我确认。

运行 `npm run local:agent -- context`，读取已确认资料、现有计划和 Agent 信息。核实官方招聘页面的开放状态、岗位类型、时间和匹配依据，通过本地 note、recommend、task 命令写入真实发现与建议。让我在岗位推荐里选择加入申请计划或跳过。没有官网成功页、申请编号或确认邮件，不能报告为已投递。

单人模式不上传个人资料到 GitHub。页面记录的研究要求不会自动运行 Agent，你需要真正执行后报告。只有我决定开启协作时，才按安装说明创建我自己的私有数据仓库、邀请指定伙伴，并私下传递安装文件；数据邀请不会自动授予源代码写入权限。

请把安装、启动和页面检查做到完成，再告诉我如何日常启动、上传材料、交给你研究以及记录申请。清楚说明实际完成和仍需我提供的信息，不把写了说明或排队任务当作完成。
