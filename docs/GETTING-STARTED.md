# 从单人开始使用

AI 求职工作台默认在自己的电脑上运行。单人使用无需 GitHub 登录、Cloudflare 账号、API 密钥或伙伴。网页不会自动运行模型；自己的 Codex / ChatGPT Agent 负责读取材料、核实岗位并写入结果。

## 安装到 Mac

准备 Node.js 22.13 或更新版本与 Git。已有 Homebrew 时运行 `brew install node@22 git`，将 Node 22 加入终端 PATH。

```sh
git clone https://github.com/Cornelius-Chen/AI-Career-Workbench.git
cd AI-Career-Workbench
npm ci
npm run local:setup -- --name "我的名字"
npm run local:start
```

打开 http://127.0.0.1:4317/team 。首次安装会进入「使用引导」，新数据库不包含作者的简历、资料、申请或示例岗位。以后双击 `start-local.command` 启动，关闭终端后网站停止。本地地址只属于当前电脑，不能当成一个远程共享网站发送给别人。

已安装用户更新：保留 `.local/`，停止网站、拉取代码、`npm ci`、`npm run local:setup`，再启动。安装命令复用现有身份、密钥和数据库；不要删除 `.local/` 或重新导入旧云端数据。

## 页面上的四步引导

1. **填写目标**：在「使用引导 → 编辑求职目标」填写简介、地区、方向、技能、全职/暑期实习、期望年份和时间。
2. **上传材料**：在「简历与文件」上传 PDF / DOCX。进入「我的工作台 → 简历与个人资料」确认申请邮箱、电话、学历、身份答案和具体经历。上传不代表解析完成；未核实材料不能作为已确认事实。
3. **联系 Agent**：在引导页获取并复制指令，粘贴给自己的 Agent。Agent 读取目标和原始材料，按官网证据研究岗位，写入有效信息、任务和推荐。没有 API 付费调用要求。若 Agent 没有网页工具，使用 `npm run local:agent`。
4. **做选择**：在「岗位推荐」选择加入申请计划或跳过；所有计划都显示在「我的申请」。只有官网成功页、申请编号或确认邮件能证明提交成功。保存一个计划不等于投递。

「Agent 信息 → 记录要求」只保存研究要求，**不会自动唤醒 Agent**。请同时把要求发给自己的 Agent，让它实际执行。

目前私人经历、投递规则、简历生成与核验功能面向美国求职。其他市场的官方要求须由 Agent 单独核实；平台不会替用户作答测评或自动确认身份资料。

## 协作是可选项

「空间设置」可切换单人或协作。切回单人只显示本人的信息，并停止本机 GitHub 数据上传和拉取，不删除历史记录。过去发送给成员的数据与文件不能撤回。

需要两人或多人时，按 [协作与 Agent 操作](LOCAL-WORKBENCH.md) 创建自己的私有数据仓库并邀请成员。每个人在自己的电脑运行并单独选择简历是否共享。数据邀请和代码写入权限是两回事；需要成员改代码时，由源码仓库所有者另行授予协作者权限，或共同使用一个 fork。
